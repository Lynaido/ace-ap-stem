📚 QUICK START (3 SIMPLE STEPS):
═══════════════════════════════════════════════════════════════

1️⃣  INSTALL DOCKER DESKTOP (ONE-TIME SETUP)

    🌐 Visit: https://www.docker.com/products/docker-desktop/

    📥 Download the right version for your Mac:
       • "Mac with Apple chip" → for M1/M2/M3 Macs
       • "Mac with Intel chip" → for older Macs

    💿 Install:
       • Open the downloaded .dmg file
       • Drag Docker icon to Applications folder
       • Open Docker Desktop from Applications
       • Wait for the whale icon (🐳) to appear in menu bar


2️⃣  START THE APPLICATION

    📁 In this folder, find the file named:
       "start-mac.command"

    🖱️  Double-click it!

    ⏱️  Wait 2-3 minutes (first time only)

    🌐 Your browser will open automatically to the app

    ⚠️  If you see a security warning:
       → System Preferences → Security & Privacy
       → Click "Open Anyway"


3️⃣  LOGIN & EXPLORE

    👤 Demo User (recommended for testing):
       Email:    demo@aas.com
       Password: demo123

       This account has sample problems and solutions!

    👨‍💼 Admin User (full access):
       Email:    admin@aas.com
       Password: admin123

    ⚠️  IMPORTANT: Change these passwords after first login!


🛑 WHEN YOU'RE DONE:
═══════════════════════════════════════════════════════════════
