                          DATA FLOW EXAMPLE
═══════════════════════════════════════════════════════════════════════════

User Clicks "Solve Problem":
────────────────────────────────────────────────────────────────────────────

1. Frontend: SolveProblemsPage.handleSolveProblem()
   │
   ├─→ createProblem(problemData)
   │   │
   │   └─→ API: POST /api/problems
   │       │
   │       └─→ Database: INSERT INTO problems
   │           │
   │           └─→ Response: { id: "prob-123", ... }
   │
   └─→ generateAISolution("prob-123")
       │
       └─→ API: POST /api/problems/prob-123/solutions
           │
           ├─→ Controller: problemsController.generateSolution()
           │   │
           │   ├─→ Database: INSERT INTO ai_jobs (status: PENDING)
           │   │
           │   ├─→ Service: openaiService.generateSolution()
           │   │   │
           │   │   ├─→ OpenAI API: gpt-4o-mini
           │   │   │   │
           │   │   │   └─→ Response: { steps: [...], finalAnswer: "...", confidence: 0.95 }
           │   │   │
           │   │   └─→ Parse & Validate Response
           │   │
           │   ├─→ Database: INSERT INTO solutions
           │   │
           │   ├─→ Database: UPDATE ai_jobs SET status='COMPLETED'
           │   │
           │   └─→ Response: { success: true, data: { solution: {...} } }
           │
           └─→ Context: dispatch(AI_GENERATION_SUCCESS, { solution })
               │
               └─→ Component: SolutionDisplay renders with real data

Total Time: 8-15 seconds
